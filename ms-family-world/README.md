# MS FAMILY WORLD — Prototype 0.1

Jeu d'aventure familial en monde ouvert, pensé d'abord pour Android.

## Inclus dans cette première tranche jouable
- Petit quartier 3D fictif : routes, trottoirs, maisons et arbres.
- Personnage contrôlable en troisième personne.
- Voiture familiale conduisible avec entrée/sortie.
- Quatre habitants nommés comme figurants de quartier.
- Première mission : retrouver la maison puis rejoindre la voiture.
- Interface en français et commandes clavier de secours.

## Lancer
Ouvrir ce dossier dans Godot 4.3+ puis lancer `main.tscn`.
Pour Android : installer les modèles d'export Android dans Godot, configurer le SDK Android/JDK, puis exporter un APK de test.

## Commandes
- PC : ZQSD ou flèches pour se déplacer, E pour interagir, F pour monter/descendre du véhicule.
- Écran : boutons INTERAGIR et MONTER / DESCENDRE.

## Limites connues du prototype
C'est une tranche verticale simple, pas un jeu AAA. Les habitants sont pour l'instant des personnages statiques de démonstration, les contrôles tactiles de déplacement et l'optimisation mobile sont à compléter. La vraie 4e dimension, le multijoueur, les sauvegardes persistantes et une IA conversationnelle seront des étapes ultérieures.
